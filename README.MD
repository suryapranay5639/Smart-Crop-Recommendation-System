# 🌾 Crop Recommendation System with Area Code Support

## 📌 Project Overview

This project is a **Machine Learning-based Crop Recommendation System** developed using Python and Tkinter GUI.

The system analyzes agricultural and soil-related parameters to recommend suitable crops for a given area. It also includes rainfall prediction, soil clustering, and Area Code support.

---

## 🚀 Features

✅ Crop Recommendation using Random Forest
✅ Crop Ranking based on prediction results
✅ Rainfall Prediction using Linear Regression
✅ Soil Clustering using KMeans
✅ Area Code Feature Encoding Support
✅ Interactive Tkinter GUI
✅ Dataset Viewer
✅ User-Friendly Interface

---

## 🛠 Technologies Used

* Python
* Tkinter
* Pandas
* NumPy
* Scikit-learn

---

## 🤖 Machine Learning Models

### 🌱 Random Forest Classifier

Used to recommend suitable crops based on soil, weather, and area-related parameters.

### 🌧️ Linear Regression

Used to predict rainfall based on the available agricultural dataset.

### 🪨 KMeans Clustering

Used to group similar soil characteristics into different clusters.

---

## 📊 Input Parameters

The system uses agricultural and environmental parameters such as:

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* Temperature
* Humidity
* Rainfall
* Area Code
* Soil-related parameters

---

## 🖥️ Application

The system provides an interactive interface where users can:

1. Enter soil and environmental parameters.
2. Provide the Area Code.
3. Get suitable crop recommendations.
4. View rainfall predictions.
5. Analyze soil clusters.
6. View the available dataset.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Crop-Recommendation-System
```

### 2. Install Required Libraries

```bash
pip install pandas numpy scikit-learn
```

### 3. Run the Project

Open the Jupyter Notebook:

```bash
jupyter notebook model.ipynb
```

Run the cells in `model.ipynb` sequentially to train the models and perform crop recommendations.
