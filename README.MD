\# 🌾 Crop Recommendation System with Area Code Support



\## 📌 Project Overview

This project is a Machine Learning-based Crop Recommendation System built using Python and Tkinter GUI.



The system:

\- Recommends the best crop using RandomForestClassifier

\- Predicts rainfall using Linear Regression

\- Performs soil clustering using KMeans

\- Supports Area Code feature encoding

\- Provides a user-friendly GUI interface



---



\## 🚀 Features



✅ Crop Ranking using Random Forest  

✅ Rainfall Stage Prediction (Regression)  

✅ Soil Clustering using KMeans  

✅ Area Code Encoding Support  

✅ Interactive Tkinter GUI  

✅ Dataset Viewer
